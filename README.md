# Our Little World — For Rose, With Love 🌹✨

A romantic, cozy, and interactive digital scrapbook website built by **Vinay** for his beloved **Rose**.

## ✨ Features
- 💌 **Welcome Screen**: Personal keepsake entrance with heartfelt message.
- 📸 **Our Memories**: Interactive polaroid photo gallery with lightbox, captions, and real memories.
- 💖 **Little Things I Love About You**: Flippable love cards celebrating Rose's smile, laugh, kindness, and late-night calls.
- 💬 **Our Conversations**: Scrapbook of real chat quotes, funny moments, and sweet sticky notes.
- 🎵 **Our Special Songs**: Audio playback for our real songs:
  - 🇮🇳 *Meri Rose* (Hindi Song • `public/songs/Meri Rose.m4a`)
  - 🇵🇭 *Rose, Ikaw ang Tahan Ko* (Filipino / Tagalog Song • `public/songs/Rose, Ikaw ang Tahan Ko.m4a`)
  - With live visualizer, progress scrubber, volume controls, and lyrics.
- ✉️ **Open When You Need Love**: Interactive wax-sealed envelopes for whenever Rose needs a reminder of love.
- 🗓️ **Our Timeline**: Chronological path of real moments, milestone photos, and memories.
- 💍 **A Little Promise**: Framed vows and quote.
- 🎁 **Final Surprise**: Confetti burst, animated pulsing heart, and lasting love note.
- ✏️ **Edit Mode & Backups**: Toggleable editing with local storage and JSON backup export/import.

## 🛠️ Built With
- **React 19** + **TypeScript** + **Vite**
- **Tailwind CSS v4**
- **Lucide React Icons**
- **Canvas Confetti**
